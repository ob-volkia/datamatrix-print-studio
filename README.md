# Data Matrix Print Studio

[Открыть конструктор](https://ob-volkia.github.io/datamatrix-print-studio/)

Готовое статическое веб-приложение для подготовки печатных этикеток из исходных кодов маркировки. Интерфейс на русском. Все согласованные параметры перечислены в SPEC.md.

## Размещение

В архиве `datamatrix-web-hosting.zip` находятся только файлы **содержимого dist/**. Распакуйте их в корень статического сайта. Сервер приложений, Python и база данных не нужны. CSV с кодами в архив и в репозиторий не входят.

### Яндекс Object Storage

Создайте бакет для статического сайта, загрузите файлы из dist с сохранением подпапок. Главная страница — `index.html`. Разрешите чтение файлов сайта. Для `.js` задайте MIME `text/javascript`, `.css` — `text/css`, `.ttf` — `font/ttf`. Подключите HTTPS по инструкции провайдера. Не включайте внешние CDN и аналитику. Домен и платёжный аккаунт пользователь выбирает отдельно; автоматической регистрации или публикации нет.

### GitHub Pages

Создайте репозиторий только для приложения, без производственных CSV/PDF. Разместите содержимое dist в корне выбранной ветки и включите Pages. Либо используйте прилагаемый `.github/workflows/pages.yml` для сборки исходников через GitHub Actions и публикации. Все пути относительные: приложение работает и в подпапке репозитория. Для бесплатного Pages репозиторий обычно публичный. Доступ из РФ нужно проверить в сетях коллег.

## Локальный запуск разработчиком

Нужен Node.js 22 или новее:

```
npm ci
npm test
npm run build
npm run dev
```

Адрес: http://127.0.0.1:4173 . Через file:// модульный Worker не работает — нужен HTTP/HTTPS. Готовые статические файлы можно раздавать любым обычным веб-сервером.

## Использование

1. Выберите исходный CSV такого же вида, как предоставленный образец: код в каждой строке целиком, без заголовков и столбцов.
2. Проверьте размеры и предпросмотр. Код квадратный; заданная сторона относится к самой матрице, без её защитного поля.
3. Настройте номер, рамку и режим страницы. А4 всегда вертикальный; поля и зазоры изменяемые. Этикетки размещаются от левого верхнего поля, слева направо, затем следующий ряд. Последний лист может быть заполнен частично.
4. При необходимости отключите «Весь файл» и задайте диапазон строк. Номер строки считается от 1. Начальный номер партии всегда относится к строке 1, а не к началу выбранного диапазона.
5. Сформируйте PDF. После завершения файл скачивается; ссылка позволяет скачать его повторно. При изменении параметров старый результат очищается.
6. Печатайте строго 100%, без подгонки под страницу.

Рамка включена; скругление выключено. Скругление не меняет форму холста и применяется только при включённой рамке. При отключении номера код центрируется по обеим осям. Защитное поле составляет не меньше одного модуля и 0,5 мм. Номер центрируется по видимой высоте цифр в области между кодом и внутренним краем рамки; от кода сохраняется защитное поле. Если содержимое не помещается, PDF не создаётся; размеры автоматически не уменьшаются.

## Данные и ошибки

- До 100 000 строк. Пустая строка внутри файла и дубликаты блокируют весь файл; первые 100 ошибок показываются с номерами строк. Завершающий перенос допускается.
- Входные данные должны соответствовать образцу: ASCII-код маркировки с AI 01 (GTIN), AI 21 и внутренним GS (байт 29). Поддерживаются CRLF, LF, CR, необязательный UTF-8 BOM. Запятые, точки с запятой и кавычки — данные, а не разделители столбцов. Байты не обрезаются и не нормализуются.
- Генерация: GS1 DataMatrix ECC 200, FNC1 в первой позиции. Внутренние данные сохраняются. Проверяется возможность кодирования; приложение не проверяет регистрацию, статус или подлинность кода в «Честном знаке».
- CSV читается только в памяти Worker. Код, CSV и PDF не отправляются на сервер. Единственный fetch приложения загружает встроенный шрифт с того же сайта. Аналитики и внешних шрифтов нет.
- В localStorage записываются только настройки макета. Сам файл, значения кодов, выбранный диапазон и начальный номер не сохраняются. При загрузке нового файла начало — 1.
- PDF хранится в памяти браузера до скачивания / изменения настроек / закрытия страницы. Скачанные файлы браузер сохраняет обычным способом на компьютер.

## PDF и производительность

PDF 1.7, векторные модули, линии рамки, текст со встроенным Liberation Sans Bold (SIL OFL). Размер страниц задаётся в физических единицах. Страницы записываются последовательно в сжатом виде, без накопления дерева всех графических объектов. Генерация выполняется в модульном Web Worker; отмена завершает Worker и освобождает незавершённый PDF.

100 000 страниц — большой PDF (порядка 90 МБ на тестовых кодах). Время зависит от компьютера и браузера; на слабых устройствах используйте диапазоны. Для тиража сначала проверьте пробный отпечаток производственным сканером: программное считывание PDF не оценивает качество конкретного принтера и материала.

## Проверки

`npm test` — импорт, дубликаты, строки, диапазон, номера и геометрия. `node tests/stress.mjs` — нагрузочный тест на синтетических 100 000 кодах (создаёт tmp/stress-100000.pdf; предварительно создайте tmp/). Результаты текущей проверки — в QA.md. Тестовые производственные данные не распространяются.

## Состав

`src/` — исходники. `public/fonts/` — локальный шрифт и его лицензия. `public/licenses/` — лицензии библиотек bwip-js / BWIPP и fflate. `dist/` — результат сборки для любого статического хостинга. Публикация: GitHub Pages, автоматическая сборка при изменении ветки main.
