# Data Matrix Print Studio — согласованная спецификация

Веб-приложение на русском. Статическая сборка для Яндекс Object Storage / GitHub Pages; для первой публикации выбран GitHub Pages. CSV и PDF обрабатываются в браузере, без серверной обработки, аналитики, CDN, внешних шрифтов. Сохраняются только настройки макета; CSV и значения кодов не сохраняются. При новом файле начальный номер сбрасывается на 1.

Вход: как предоставленный образец CSV, одна строка = один код, без заголовка и столбцов. Пунктуация и GS сохраняются. Переносы CRLF/LF; обычный последний перенос разрешён. Внутренние пустые строки и дубликаты блокируют экспорт с номерами строк. До 100 000 строк. Порядок сохраняется. Генерация GS1 DataMatrix ECC200 с начальным FNC1 и сохранением байтов полезных данных.

Холст по умолчанию 25×25 мм, независимые ширина/высота. Переключатель «Сохранять пропорции холста» фиксирует текущее соотношение; по умолчанию включён, состояние сохраняется. Код квадратный 15×15 мм, одно поле стороны. Номер полужирным шрифтом без засечек 7 пт; шрифт встроен в PDF. Номер включён; по умолчанию снизу, выбор сверху/снизу. Код и номер центрированы по ширине, группа по высоте. Без номера код центрирован по обеим осям. Защитная зона вокруг кода не меньше одного модуля. Номер центрируется в свободной области между кодом и внутренним краем рамки по видимым границам цифр, с сохранением защитной зоны.

Начальный номер 1, изменить для продолжения партии. Цифры: авто минимум 5 с учётом последнего номера ВСЕГО файла, ручное переопределение. Номера не обрезаются. Выгрузка всего файла или диапазона строк с сохранением нумерации относительно всей партии.

Рамка включена, толщина 0,4 пт, отступ от края 1 мм. Скругление выключено, радиус 1,3 мм. Переключатели независимые; скругление применяется только к рамке.

PDF векторный: либо одна этикетка на странице точного размера, либо А4 вертикальный 210×297 мм. А4: поля 5 мм, промежутки 2 мм, оба значения изменяемые. Авторасчёт рядов/столбцов без масштабирования. Слева направо, сверху вниз. Диапазон всегда с первой позиции нового листа. Нет стартовой ячейки, вылетов или меток реза. Печать строго 100%.

Любое непомещение блокирует экспорт с объяснением. Автоуменьшения нет. Предпросмотры увеличенной этикетки и листа А4, переход к строке. Прогресс и отмена генерации через Web Worker. Векторные данные и шрифт включены локально. Окончательная пригодность отпечатка проверяется производственным сканером перед тиражом.
